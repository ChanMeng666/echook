# Claude Code

[`AGENTS.md`](AGENTS.md) is the single full operating guide, imported above. Claude Code ignores `AGENTS.md` whenever a `CLAUDE.md` exists, so this file exists only to import it; edit the guide there, never here. It is deliberately not a symlink (they are unreliable on Windows, this project's primary platform) and not a copy (a hand-kept copy can drift).

Add an instruction below only if it applies to Claude Code alone. Anything Cursor or Codex agents should also follow belongs in `AGENTS.md`.
